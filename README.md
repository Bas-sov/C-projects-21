# C-projects-21

Командные проекты, выполненные в рамках отборочного интенсива Школы 21: две консольные игры на языке C — клеточный автомат Конвея «Игра в жизнь» и классический Pong для двух игроков.

## Содержимое

| Файл | Описание |
|---|---|
| `game_of_life.c` | Клеточный автомат «Жизнь» на ncurses с тремя «поколениями» клеток и настраиваемой скоростью |
| `pong.c` | Классическая игра Pong для двух игроков в терминале |
| `patterns/` | Готовые начальные конфигурации полей для «Жизни» |

## Требования

Инструкции приведены **для Linux**. Программы используют POSIX-возможности (`/dev/tty`, ANSI-escape-последовательности) и библиотеку ncurses — сборка и запуск под Windows не предусмотрены.

Необходимо:

- компилятор C: `gcc`;
- библиотека **ncurses** с заголовочными файлами (нужна для «Жизни»);
- стандартный эмулятор терминала.

## Установка зависимостей

**Ubuntu / Debian:**

```bash
sudo apt update
sudo apt install gcc libncurses-dev
```

**Fedora / RHEL:**

```bash
sudo dnf install gcc ncurses-devel
```

**Arch Linux:**

```bash
sudo pacman -S gcc ncurses
```

## Сборка

Из корня репозитория:

```bash
gcc game_of_life.c -o game_of_life -lncurses
gcc pong.c -o pong
```

## Запуск

### Игра «Жизнь»

Программа считывает начальное поле (25 строк × 80 столбцов) из стандартного ввода. Используйте один из готовых паттернов из `patterns/`:

```bash
./game_of_life < patterns/1.txt
```

**Управление:**

| Клавиша | Действие |
|---|---|
| `A` | Увеличить скорость (10 уровней, шаг 20 мс) |
| `Z` | Уменьшить скорость |
| `Пробел` | Выйти из игры |

**Особенности:**

- Поле **тороидальное**: края склеены, паттерны, выходящие за границу, появляются с противоположной стороны.
- Клетки имеют 3 «поколения» (`.` → `o` → `@`), циклически сменяющие друг друга, пока клетка жива.
- Правила классические: живая клетка с 2–3 соседями выживает, у пустой клетки с 3 соседями рождается новая.

### Pong

```bash
./pong
```

Игра для двух игроков за одной клавиатурой. Режим **пошаговый**: ход совершается нажатием клавиши и `Enter`. Побеждает игрок, первым набравший **21 очко**.

**Управление:**

| Клавиша | Действие |
|---|---|
| `A` | Игрок 1 — ракетка вверх |
| `Z` | Игрок 1 — ракетка вниз |
| `K` | Игрок 2 — ракетка вверх |
| `M` | Игрок 2 — ракетка вниз |
| `Пробел` | Пропустить ход (мяч движется без сдвига ракеток) |

## Формат файлов паттернов

Файлы в `patterns/` содержат 25 строк по 80 чисел, разделённых пробелами:

- `0` — пустая клетка;
- `1`–`3` — живая клетка на одном из трёх «поколений».

Вы можете создать собственную конфигурацию в этом формате и запустить игру с ней:

```bash
./game_of_life < my_pattern.txt
```
